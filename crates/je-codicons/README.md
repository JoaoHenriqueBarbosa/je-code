# je-codicons

Os ícones do VS Code (codicons): a tabela de id para code point, gerada de `codiconsLibrary.ts` e
`codicons.ts` do VS Code 1.143.1 por `scripts/gen_codicons.py`, e a fonte `assets/codicon.ttf`.

## Origem e licença

- `assets/codicon.ttf`: copiado do build oficial do VS Code 1.143.1 (`resources/app/out/media/codicon.ttf`),
  que o empacota a partir de `@vscode/codicons` (microsoft/vscode-codicons). As fontes e ícones dos codicons
